## 🛠️ 하드웨어 사양 및 개발 환경

### OK-89S52 V1.0 순정 하드웨어 사양
* **CPU / 클럭**: Atmel `AT89S52-24PC` / `24PI` @ `24 MHz` (`AT89S51`, `AT89S8253` 호환)
* **프로그램 메모리 (ROM)**: CPU 내장 `8 KB` ISP Flash (`0x0000`~`0x1FFF`) + 외부 확장 `32 KB` ROM 소켓 (`27C256` 또는 `29C256`, 사용자 프로그램용 옵션)
* **데이터 메모리 (RAM)**: CPU 내장 `256 B` RAM (`0x00`~`0xFF`, 순정 보드에는 외부 확장 SRAM 없음)
* **CPU 직접 제어 I/O**: RS-232C 직렬통신(`CN4`), `+5V` 부저(`P3.5`), 스피커 출력(`CN5`, `P1.0`/`T2`), 키 입력 4개(`KEY4`~`KEY1`, `P1.4`~`P1.1`), 사용자 인터럽트 스위치 `SW2`(`-INT0`/`P3.2`), 리셋 스위치 `SW1`, ISP 커넥터 2종(AT89S `CN2`, AVR `CN3`)
* **외부 확장 I/O (`0x8000`~`0x8500`)**:
  * `0x8000`~`0x800F`: `DS12C887` 배터리 백업 리얼타임 클럭 (RTC)
  * `0x8100` / `0x8200`: 8자리 7-세그먼트 LED (`SEG_PATTERN` / `DIG_SELECT`) 및 상태표시 LED 4개 (`LED4`~`LED1`, `0x8200` 하위 4비트 공유)
  * `0x8300` / `0x8301`: 16자×2행 텍스트형 LCD 모듈 (`LCD_WR_INST` / `LCD_WR_DATA`, 백라이트 지원)
  * `0x8400`~`0x8407`: `ADC0809` 8채널 8비트 A/D 컨버터 (`0V`~`+5V`, `IN0` 전압 `VR1` · `IN1` 온도 `LM35` · `IN2` 조도 `CdS` + 4채널 입력 `CN6`)
  * `0x8500`: `DAC0800` 8비트 D/A 컨버터 (`0V`~`+10V` 또는 `-10V`~`+10V` 선택)
* **전원 / 기판**: `+5V`, `±15V`(`±12V` 사용 가능, 아날로그 회로용), `160×130 mm` 양면 에폭시 기판

### 빌드 툴체인
* **언어 표준**: SDCC C11 (`--std-sdcc11`)
* **컴파일러 / 툴체인**: SDCC (`sdcc`, `sdas8051`, `sdld`), `srec_cat`
* **빌드 프레임워크**: GNU Make + [`mk-build-raccoon`](../mk-build-raccoon) (`sdcc_mcs51.mk`)

## 🚀 빌드 및 업로드 방법

각 실습 디렉토리에는 개별 `Makefile`이 포함되어 있으며, 루트의 [`prj_mcs51.mk`](prj_mcs51.mk)를 참조합니다.

### 1. 순정 보드 ISP 단독 모드 (기본: `USE_PAULMON=0`)
개조하지 않은 순정 OK-89S52 보드의 내장 `8 KB` ISP Flash(`0x0000`~`0x1FFF`)에 직접 굽기 위한 기본 설정입니다. 코드 `8 KB`(`--code-size 0x2000`), 외부 SRAM 미사용(`--xram-size 0`) 기준으로 링크합니다.

```bash
$ cd Exp18_8
$ make clean && make
# 산출물: bin/Exp18_8.ihx, bin/Exp18_8.hex, bin/Exp18_8.mem, bin/Exp18_8.cdb
```

### 2. PAULMON2 외부 SRAM 확장 보드 모드 (`USE_PAULMON=1`)
순정 OK-89S52에는 외부 SRAM이 없으므로, 외부 메모리 소켓 등을 SRAM(코드·데이터 통합 `/PSEN`·`/RD`)으로 확장 개조하고 내장 Flash(`0x0000`~`0x1FFF`)에 PAULMON2 모니터를 구운 환경을 위한 설정입니다. `USE_PAULMON=1`을 지정하면 외부 SRAM 코드 영역(`--code-loc 0x2000`, `16 KB`)과 데이터 영역(`--xram-loc 0x6000`, `8 KB`)으로 분리 링크합니다.

> **참고**: 기본(`USE_PAULMON=0`) 빌드와 `USE_PAULMON=1` 빌드 간 전환 시에는 링크 주소가 달라지므로 반드시 `make clean` 후 다시 빌드해야 합니다.

```bash
$ cd Exp18_6
$ make clean && make USE_PAULMON=1
$ make paulmon USE_PAULMON=1 TTY_DEV=/dev/ttyUSB0
```

### 3. 전체 예제 일괄 컴파일 및 정리
```bash
# 전체 컴파일 (ISP 단독 모드 기본)
$ for dir in Exp*; do make -C "$dir" clean && make -C "$dir" || break; done

# 전체 컴파일 (PAULMON2 외부 SRAM 확장 보드 모드)
$ for dir in Exp*; do make -C "$dir" clean && make -C "$dir" USE_PAULMON=1 || break; done

# 전체 빌드 산출물 정리
$ for dir in Exp*; do make -C "$dir" clean; done
```
